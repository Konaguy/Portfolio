# Vulnerability Management RAG Assistant

Ask questions about your ingested Tenable findings and security policies, and
get contextual, policy-grounded remediation guidance with citations back to
the exact findings and policy sections used.

This is a portfolio demo. See the project `README.md` for the architecture,
how the multi-agent LangGraph pipeline works, and how to point it at a real
Qdrant instance and your own Tenable exports.
